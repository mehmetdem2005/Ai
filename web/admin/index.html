Detaylı dashboard sonraki modülde gelecek.

Bültenler

Yayımlanan tüm bültenler — düzenle, sil, yeniden işle.

Modül iskeleti hazır, içerik bir sonraki adımda.

Makaleler

Pipeline'a giren ham makaleler — kaynak, tarih, eşleştiği niche.

Liste + filtre + detay görünümü bir sonraki adımda.

Site metinleri

Landing, hakkında, abonelik sayfalarındaki tüm metinler. Kod düzenlemeden değiştir.

site_pages + site_strings tabloları + editör arayüzü bir sonraki adımda.

Kaynaklar

RSS feed'leri, PubMed/ClinicalTrials/medRxiv/bioRxiv entegrasyonları.

Mevcut `feeds` tablosunu liste + ekle/sil ile yöneten panel bir sonraki adımda.

Cron & worker

Manuel tetikle, geçmiş çalıştırmaların log'unu gör, başarısızlıkları izle.

Trigger butonu + GitHub Actions runs listesi bir sonraki adımda.

Pro kullanıcılar

Abone listesi, niche tanımları, son brief teslimi.

profiles + niches + briefs join'i ile liste, detay sayfası bir sonraki adımda.

Erişim & roller

Kim admin, kim editor, kim viewer. Audit log her aksiyonu kaydeder.

admin_roles tablosu + rol atama UI bir sonraki adımda.

Audit log

Her admin aksiyonu — kim, ne zaman, ne yaptı, önce/sonra.

admin_audit tablosu + filtre + detay viewer bir sonraki adımda.

Ayarlar

Env değişkenleri (read-only), API anahtarları, integration durumu.

Vercel env + Supabase status + sağlık check sonraki adımda.
